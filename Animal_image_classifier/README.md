# Animal Image Classifier

โปรเจกต์จำแนกภาพสัตว์ด้วย Deep Learning โดยใช้ TensorFlow และ Keras
เพื่อทำนายภาพที่ผู้ใช้อัปโหลดว่าเป็น **นก (Bird), แมว (Cat) หรือสุนัข (Dog)**
และแสดงคะแนนการทำนายผ่านเว็บแอป Gradio

## 1. แหล่งที่มา จำนวนข้อมูล และการแบ่งชุดฝึก/ชุดทดสอบ

### แหล่งที่มาของข้อมูล

โค้ดกำหนดให้อ่านภาพจากโฟลเดอร์ภายในโปรเจกต์ ได้แก่

-   `train_images/` --- ชุดข้อมูลสำหรับฝึกโมเดล (Training set)
-   `test_images/` --- ชุดข้อมูลที่ใช้ตรวจสอบโมเดลระหว่างฝึก (Validation set
    ตามโค้ด)

ภายในแต่ละโฟลเดอร์ควรแยกภาพตามคลาส เช่น `bird/`, `cat/` และ `dog/`
เพื่อให้ระบบอ่านป้ายกำกับจากชื่อโฟลเดอร์ได้

-   **แหล่งที่มาดั้งเดิมของภาพ:** (https://www.kaggle.com/datasets/ashishpahal/animal-images-5-classes-bird-cat-dog-fish-rabbit/data)
-   **จำนวนภาพทั้งหมด:** 6000
-   **จำนวนภาพชุดฝึก:** 4800 `train_images/`
-   **จำนวนภาพชุดตรวจสอบ:** 1600 `test_images/`
-   **สัดส่วนการแบ่งข้อมูล:** train 80 test 20

หมายเหตุ: ไฟล์โค้ดที่ได้รับไม่ได้ระบุแหล่งที่มาดั้งเดิมหรือจำนวนภาพจริง และไม่มีชุด Test
แยกให้เห็น โดยโค้ดใช้ `test_images/` เป็นชุด Validation

### การเตรียมข้อมูล

-   ปรับขนาดภาพเป็น `224 × 224` พิกเซล
-   ปรับค่าสีให้อยู่ในช่วง `0–1` โดยหารด้วย `255`
-   ชุดฝึกเพิ่มความหลากหลายของภาพด้วยการหมุน ขยับภาพ และพลิกภาพในแนวนอน
-   ชุด Validation ปรับเฉพาะค่าสี ไม่ได้เพิ่มความหลากหลายของภาพ

## 2. แบบจำลองที่ใช้ ผลประเมินหลัก และข้อจำกัด

### แบบจำลองที่ใช้

ใน `models.py` มีแบบจำลอง

1. **Transfer Learning (MobileNetV2):** ใช้ MobileNetV2 ที่มีน้ำหนักเริ่มต้นจาก
    ImageNet โดยตัดชั้นจำแนกเดิมออก และเพิ่มชั้นสำหรับจำแนกสัตว์ 3 คลาส ได้แก่ Global
    Average Pooling, Dense, Dropout และ Softmax

ใน `train.py` โค้ดที่เปิดใช้งานสำหรับฝึกจริงคือ MobileNetV2 แบบ Transfer Learning

### ค่าตั้งต้นของการฝึก

-   ขนาดภาพ: `224 × 224`
-   Batch size: `32`
-   Epochs: `15`
-   จำนวนคลาส: `3`
-   Optimizer: Adam
-   Learning rate ของ Transfer Learning: `0.0001`
-   Loss function: `categorical_crossentropy`
-   Metric: `accuracy`

### ผลประเมินหลัก

ไฟล์ `evaluate.py` ใช้แสดงกราฟเปรียบเทียบผลระหว่างชุดฝึกและชุด Validation ได้แก่ -
**Accuracy:** Training Accuracy และ Validation Accuracy - **Loss:**
Training Loss และ Validation Loss

-   **Accuracy / Validation Accuracy :** 0.9792
-   **Loss / Validation Loss :** 0.0617

หมายเหตุ: ไฟล์ที่ได้รับยังไม่มีผลประเมินเป็นตัวเลข จึงไม่สามารถระบุค่าความแม่นยำจริงได้

### ข้อจำกัด

-   จำแนกได้เฉพาะนก แมว และสุนัข
-   ผลการทำนายขึ้นอยู่กับคุณภาพของภาพ แสง มุมมอง และความหลากหลายของข้อมูล
-   เว็บแอปต้องมีไฟล์ `model/transfer_model.h5` จึงจะเริ่มทำงานได้
-   จากโค้ดที่ให้มาไม่พบชุดทดสอบอิสระแยกจากชุด Validation
    จึงยังสรุปผลกับข้อมูลใหม่ทั้งหมดไม่ได้

## 3. ขั้นตอนติดตั้งแพ็กเกจและคำสั่งรันแอปบนเครื่อง

### สิ่งที่ต้องเตรียม

-   Python เวอร์ชันที่รองรับ TensorFlow
-   ไฟล์โค้ดของโปรเจกต์
-   โฟลเดอร์ `train_images/` และ `test_images/` ที่จัดภาพแยกตามคลาส

### ติดตั้งแพ็กเกจ

เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วสร้าง Virtual
Environment

``` bash
python -m venv .venv
```

เปิดใช้งาน Virtual Environment

**Windows**

``` bash
.venv\Scripts\activate
```

**macOS / Linux**

``` bash
source .venv/bin/activate
```

ติดตั้งแพ็กเกจตามไฟล์ `requirements.txt`

``` bash
pip install -r requirements.txt
```

### เตรียมโฟลเดอร์บันทึกโมเดล

สร้างโฟลเดอร์ `model/` หากยังไม่มี

``` bash
mkdir model
```

### ฝึกโมเดล

หากยังไม่มีไฟล์โมเดล ให้รันคำสั่ง

``` bash
python train.py
```

เมื่อฝึกเสร็จ โค้ดจะบันทึกโมเดลที่ `model/transfer_model.h5` และแสดงกราฟ Accuracy
กับ Loss ต้องมีชุดข้อมูลใน `train_images/` และ `test_images/` ก่อนเริ่มฝึก

### รันเว็บแอป

เมื่อมีไฟล์ `model/transfer_model.h5` แล้ว ให้รัน

``` bash
python app.py
```

เปิดเว็บเบราว์เซอร์ที่ `http://127.0.0.1:7860`
ซึ่งเป็นโฮสต์และพอร์ตเริ่มต้นที่กำหนดในโค้ด

## 4. วิธีใช้งาน พร้อมตัวอย่างข้อมูลนำเข้า

1.  ติดตั้งแพ็กเกจและเตรียมไฟล์โมเดลให้เรียบร้อย
2.  รันคำสั่ง `python app.py`
3.  เปิด `http://127.0.0.1:7860`
4.  อัปโหลดภาพนก แมว หรือสุนัข
5.  ดูผลการทำนายและคะแนนของแต่ละคลาสที่หน้าเว็บ

### ตัวอย่างข้อมูลนำเข้า

-   **ข้อมูลนำเข้า:** ภาพนก เช่น `bird.jpg`
-   **ผลลัพธ์:** เว็บแอปแสดงคะแนนของคลาส `Bird`, `Cat` และ `Dog`

ตัวอย่างนี้เป็นรูปแบบการใช้งานเท่านั้น ไม่ใช่ผลทำนายจากการรันจริง
คะแนนที่ได้ขึ้นอยู่กับภาพและโมเดลที่ฝึกไว้

## 5. คำอธิบายไฟล์และโฟลเดอร์สำคัญ

  -----------------------------------------------------------------------
  ไฟล์/โฟลเดอร์                         หน้าที่
  ----------------------------------- -----------------------------------
  `app.py`                            สร้างเว็บแอป Gradio รับภาพจากผู้ใช้
                                      เตรียมภาพ และแสดงคะแนนการทำนาย

  `config.py`                         กำหนดค่าต่าง ๆ เช่น ขนาดภาพ Batch size
                                      จำนวน Epochs จำนวนคลาส และพาธข้อมูล

  `dataset.py`                        โหลดภาพจากโฟลเดอร์ สร้าง Data
                                      Generator
                                      และเพิ่มความหลากหลายให้ภาพชุดฝึก

  `models.py`                         สร้างแบบจำลอง Custom CNN และ
                                      MobileNetV2 แบบ Transfer Learning

  `train.py`                          โหลดข้อมูล ฝึก MobileNetV2 บันทึกโมเดล
                                      และเรียกแสดงกราฟผลการฝึก

  `evaluate.py`                       วาดกราฟ Accuracy และ Loss
                                      ของชุดฝึกและชุด Validation

  `requirements.txt`                  ระบุแพ็กเกจที่ต้องติดตั้ง ได้แก่ TensorFlow,
                                      NumPy, Pillow, Gradio และ
                                      Matplotlib

  `train_images/`                     เก็บภาพสำหรับฝึกโมเดล
                                      โดยแยกโฟลเดอร์ตามคลาส

  `test_images/`                      เก็บภาพที่โค้ดใช้เป็นชุด Validation
                                      โดยแยกโฟลเดอร์ตามคลาส

  `model/transfer_model.h5`           ไฟล์โมเดลที่ `train.py` บันทึก และ
                                      `app.py` โหลดมาใช้ทำนาย

  `.venv/`                            โฟลเดอร์สภาพแวดล้อม Python
                                      แยกสำหรับติดตั้งแพ็กเกจ (ถ้าสร้างไว้)
