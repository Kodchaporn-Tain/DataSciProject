# Traffic Analytics Prediction (ระบบพยากรณ์ปริมาณการจราจร AADT)

## 1\. แนวคิด ปัญหาที่ต้องการแก้ และประโยชน์ของแอป

- **ปัญหา:** กรมทางหลวงมีความจำเป็นต้องวางแผนการซ่อมบำรุงและขยายช่องจราจรล่วงหน้า การประเมินด้วยสายตาหรือการคาดเดาอาจทำให้เกิดความผิดพลาดในการจัดสรรงบประมาณ  
- **แนวคิด:** พัฒนาแบบจำลอง Machine Learning เพื่อทำนายปริมาณการจราจรเฉลี่ยรายวันต่อปี (Annual Average Daily Traffic: AADT) จากปีงบประมาณและข้อมูลสายทาง
- **ประโยชน์:** เป็นข้อมูลเชิงประจักษ์ประกอบการตัดสินใจ ช่วยให้การจัดสรรงบประมาณซ่อมบำรุงถนนและวางแผนโครงสร้างพื้นฐานมีความแม่นยำและมีประสิทธิภาพสูงสุด

## 2\. แหล่งที่มา จำนวนข้อมูล และการแบ่งชุดฝึก/ชุดทดสอบ

- **แหล่งที่มา:** ประวัติการสำรวจปริมาณจราจร กรมทางหลวง (`v_aadt_2565.csv`) ผ่านเว็บไซต์ data.go.th  
- **จำนวนข้อมูล:**  
  - ข้อมูลตั้งต้นทั้งหมด: 8,250 รายการ 
  - หลังผ่านการคัดกรองสายทางที่มีประวัติอย่างน้อย 3 ปี และสร้าง Lag Feature (ปริมาณรถปีก่อนหน้า): เหลือ 7,315 รายการ 
- **การแบ่งชุดข้อมูล (Time-Based Train-Test Split):**  
  - ชุดฝึกสอน (Train Set, ปี \< 2566): 6,628 รายการ
  - ชุดทดสอบ (Test Set, ปี 2566): 687 รายการ (จำลองสถานการณ์พยากรณ์อนาคตจริง) 

## 3\. แบบจำลองที่ใช้ ผลประเมินหลัก และข้อจำกัด

- **แบบจำลอง:** Random Forest Regressor (ร่วมกับการทำ Log Transformation `np.log1p` เพื่อปรับความเบ้ของข้อมูลและป้องกันค่าติดลบ) 
- **ผลประเมินหลัก (Performance Metrics):**  
  - **R-squared (\$R^2\$ Score):** 0.9153 (หรือ 0.9158 บนหน้าเว็บแอป)   
  - **Mean Absolute Error (MAE):** 829.43 คัน/วัน  
  - **Root Mean Squared Error (RMSE):** 1,900.01 คัน/วัน  
- **ข้อจำกัด:** แบบจำลองอาจมีความคลาดเคลื่อนในสายทางที่มีการเติบโตหรือการพัฒนาพื้นที่แบบก้าวกระโดดผิดปกติ ซึ่งไม่มีรูปแบบในข้อมูลอดีต

## 4\. ขั้นตอนติดตั้งแพ็กเกจและคำสั่งรันแอปบนเครื่อง

1. ติดตั้งแพ็กเกจที่จำเป็นผ่านไฟล์ `requirements.txt`:  
     
   pip install \-r requirements.txt  
     
2. รันเว็บแอปด้วยคำสั่ง:  
     
   python app.py  
     
3. เปิดบราวเซอร์ไปที่ลิงก์ Localhost ที่แสดงขึ้นมา (ปกติคือ `http://localhost:7860`)

## 5\. วิธีใช้งาน พร้อมตัวอย่างข้อมูลนำเข้า

- **วิธีใช้งาน:**  
  1. กำหนด **ปีงบประมาณ (Budget Year)** ที่ต้องการพยากรณ์ผ่านแถบ Slider (เช่น ปี 2566 หรือ 2567\)  
  2. เลือก **สายทาง (Link ID & Road Code)** จากเมนูดรอปดาวน์   
  3. กดปุ่ม **"ประมวลผลการทำนาย"** เพื่อดูผลลัพธ์ปริมาณจราจรที่คาดการณ์ (คัน/วัน)  
- **ตัวอย่างข้อมูลนำเข้า:**  
  - ปีงบประมาณ: `2566`  
  - สายทาง: `98 - ทางหลวงหมายเลข ...` (หรือเลือกจากตัวอย่างดรอปดาวน์ในระบบ)

## 6\. URL ของเว็บแอป

- **Local URL:** `http://localhost:7860`

## 7\. คำอธิบายไฟล์และโฟลเดอร์สำคัญ

- `app.py`: โค้ดหลักสำหรับสร้างและรันเว็บแอปด้วย Gradio Framework  
- `models/traffic_volume_rf_model.pkl`: ไฟล์โมเดล Machine Learning (Random Forest) ที่ผ่านการฝึกสอนแล้ว  
- `models/latest_lag_data.pkl`: ไฟล์เก็บข้อมูลปริมาณรถปีก่อนหน้า (Lag Data) สำหรับใช้ป้อนให้โมเดลทำนาย  
- `Traffic_Volume_Prediction.ipynb`: สมุดบันทึก Jupyter Notebook สำหรับกระบวนการเตรียมข้อมูล เทรนโมเดล และประเมินผล   
- `v_aadt_2565.csv`: ชุดข้อมูลดิบประวัติการสำรวจปริมาณจราจร กรมทางหลวง  
- `requirements.txt`: รายชื่อไลบรารีและแพ็กเกจที่ต้องใช้ในการรันโปรเจกต์  
- `.gitignore`: กำหนดไฟล์ที่ไม่ต้องการให้อัปขึ้น Git (เช่น ฟอนต์ `.ttf`, โฟลเดอร์ `.venv`)
